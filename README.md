## 1. 安裝（第一次）

1. 下載 **Godot 4.7.2**（Windows 64-bit，**不要**選 .NET 版，也**不要**用更新的版本）
   👉 https://godotengine.org/download/archive/4.7.2-stable/
2. 解壓 Godot，直接執行 `Godot_v4.7.2-stable_win64.exe`（不用安裝）
3. 解壓這個專案壓縮檔到任意資料夾
4. Godot 專案管理員 → **匯入**（Import）→ 選專案資料夾裡的 `project.godot` → **匯入並編輯**（Import & Edit）
5. 第一次開啟會跑一陣子匯入進度條，等它跑完再動

## 2. 資料夾規則

| 資料夾 | 能不能改 |
|---|---|
| `_my/` | ✅ **你的東西全部放這裡** |
| 其他所有資料夾 | ❌ 只能看、只能拖，**不要改、不要存檔進去** |

存檔時看一下路徑是不是 `res://_my/...`。存到別的地方，重灌時就會不見。
哪個資料夾裡有什麼 → [零件手冊 §1](零件手冊.md#1-東西在哪裡)

## 3. 每週上課流程

每週都是同一個套路：**打開示範場景看看 → 另存到 `_my/` → 拖東西、調數值 → 按 F6 試玩**。
中途才加入的話，把那一週的起始場景另存到 `_my/` 就能直接開始。

### 3.1 W1：機制卡與零件

1. **抽卡**：打開 `levels/CardDraw.tscn` → 按 **F6** → 按「抽卡」
2. **逛展示間**：打開 `levels/Showroom.tscn` → 按 **F6**，看看各種零件怎麼動
3. **另存玩具箱**：打開 `levels/_starts/W1_ToyBox.tscn` → **場景 → 另存場景為**（Scene → Save Scene As）→ 存到 `_my/`
   （之後都改 `_my/` 裡的這份，不要改原本那份）
4. **拖東西進去**：拖到哪裡見第 5 節
5. **調數值**：點節點 → 右邊 Inspector 拉拉桿、選下拉選單，滑鼠停在欄位上會有中文說明。
   玩家的跑速、跳多高：點 **Player**，看「移動參數」「按鍵手感」
6. **試玩**：按 **F6**（執行目前場景）

細節 → 每張卡怎麼操作看 [速查表 §4](速查表.md#4-每張卡怎麼操作要搭配什麼)；每個零件的設定看 [零件手冊 §3](零件手冊.md#3-零件一覽blocks)；
訊號怎麼連（例如按鈕開門）看 [速查表 §2、§3](速查表.md#2-誰會發出訊號連線的起點)

### 3.2 W3：手感果汁（Juice）

1. **先感受差別**：打開 `levels/_starts/W3_JuiceBox.tscn` → 按 **F6** → 從頭跑到終點，途中按 **0** 把全部 Juice 關掉／打開對照
2. **拖 Juice**：從 `juice/` 拖到 **Player → Juice** 底下，不調任何東西就有效果
3. **選什麼時候播**：點那個 Juice → Inspector 的 `timing` 下拉（跳躍時、落地時、受傷時…）。同一種 Juice 可以拖好幾個，各選不同的時機
4. **練習關**：`levels/_starts/W3_JuicePractice.tscn` 另存到 `_my/` → 照天上告示牌的題目做 → 按 **F6**，做對的告示牌會變綠色

細節 → 每個 Juice 的設定、用訊號播、背景音樂看 [零件手冊 §6](零件手冊.md#6-手感組件-juicejuice)；告示牌沒變綠看 [零件手冊 §8](零件手冊.md#8-練習關w3_juicepracticew4_skinpractice)

### 3.3 W4：套皮與 UI

1. **先看換完長什麼樣子**：打開 `levels/_starts/W4_SkinBox.tscn` → 按 **F6**；
   標題畫面打開 `levels/_starts/_W4SkinBox/ui/TitleDemo.tscn` → 按 **F6**
2. 自己的圖片、字型都放在 `_my/` 底下（例如 `_my/art/`）
3. **用了別人的素材要記下來**：寫在 `_my/CREDITS.txt` → [零件手冊 §7](零件手冊.md#7-套皮與-uiw4)
4. 想做什麼就看對應的章節：

| 想做什麼 | 做法 | 細節 |
|---|---|---|
| 換零件外觀（終點、門、敵人…） | 從 `skins/` 拖 `Skin` 到零件**底下**，圖拖進 `texture_normal` | [零件手冊 §7.1](零件手冊.md#71-換零件外觀-skins) |
| 加背景、統一色調 | 從 `skins/` 拖 `SkinBackground`、`ColorGrade` 進關卡 | [零件手冊 §7.1](零件手冊.md#71-換零件外觀-skins) |
| 換 HUD、暫停選單、過關畫面 | `ui/templates/` 的範本右鍵**再製**到 `_my/` 改 → 拖進關卡 | [零件手冊 §7.2](零件手冊.md#72-自己的-hud暫停選單過關畫面-ui) |
| 做標題畫面 | 標題範本再製到 `_my/` → 「開始遊戲」選自己的關卡 → 右鍵**設為主場景** | [零件手冊 §7.2](零件手冊.md#72-自己的-hud暫停選單過關畫面-ui) |
| 手機也能玩 | 從 `ui/` 拖 `TouchControls` 進關卡 | [零件手冊 §7.2](零件手冊.md#72-自己的-hud暫停選單過關畫面-ui) |
| 換角色動畫 | `Sprite2D` 換成 `AnimatedSprite2D`，拖 `Juice_Animator` 到 Player → Juice | [零件手冊 §7.3](零件手冊.md#73-角色動畫-juice_animator) |
| 換地形 | `art/terrain_tile.tres` 再製到 `_my/`，照範本格子畫圖 | [零件手冊 §7.4](零件手冊.md#74-地形) |

5. **練習關**：`levels/_starts/W4_SkinPractice.tscn` 另存到 `_my/` → 照天上告示牌的題目做（往右走看後面的題目）→ 按 **F6**；
   告示牌沒變綠看 [零件手冊 §8](零件手冊.md#8-練習關w3_juicepracticew4_skinpractice)

動畫名稱、各種皮的欄位一覽 → [速查表 §6](速查表.md#6-w4-套皮與-ui)

### 3.4 額外功能：作弊模式

- **給玩家的秘技**：從 `cheats/` 拖 `Cheat` 進關卡，勾要開什麼。預設在遊戲裡按 **W W S S A D A D** 打開
- **給自己測關卡**：從 `cheats/` 拖 `DevCheats` 進關卡，F6 後按 **`**（Tab 上面那顆鍵）打開清單。只在編輯器裡有效，不用記得拔掉

細節 → [零件手冊 §9](零件手冊.md#9-作弊模式cheats)

## 4. 建立自己的關卡

要做一個真正給別人玩的關卡時：

1. 打開 `levels/_Template.tscn`
2. **什麼都還沒改之前**，先按 **場景 → 另存場景為**（Scene → Save Scene As）→ 存到 `_my/`，取個名字（例如 `MyLevel.tscn`）
   - 上方分頁變成你取的名字，之後改的、存的都是 `_my/` 裡這份
   - 先改了才另存的話，按 Ctrl+S 會存回原本的模板，重灌就不見了
3. 在 `_my/` 裡那份上按右鍵 → **設為主場景**（Set as Main Scene）
   - 做了標題畫面的話，改成把**標題**設為主場景，關卡在標題的「開始遊戲」按鈕選
4. 之後按 **F5** 就會直接跑你的關卡（或標題），匯出網頁版也是從這裡開始

> 重灌專案後主場景會跑掉，要重做第 3 步。

> ⚠ **不要用檔案總管（Windows 的資料夾視窗）複製 `.tscn` 檔**，也不要從同學那裡直接複製關卡檔過來。
> 檔案總管複製出來的檔案跟原本那份用同一個編號，Godot 會把兩個當成同一個檔案，
> 結果「設為主場景」按了沒反應、改到的是別份。要複製一律在 Godot 裡用「另存場景為」。

## 5. 東西要拖到哪裡

從左下角「檔案系統」把 `.tscn` 拖到左上角「場景」樹上：

```
你的關卡
├── Player
│   ├── Mechanics   ← mechanics/ 的機制卡（抽到的那張）
│   ├── Juice       ← juice/ 的手感組件
│   └── Abilities   ← abilities/ 的攻擊能力（近戰、遠程）
├── RespawnHandler  ← 死掉後讓你重生（範本已經放好）
├── KeySettings     ← 改按鍵、加自己的按鍵（範本已經放好）
├── ValueSettings_Health ← 血量（範本已經放好；金幣、鑰匙再拖一個 ValueSettings）
├── Room1、Room2…   ← blocks/Room.tscn（房間，見下面 5.1）
└── （直接放在關卡底下） ← blocks/ 的零件（按鈕、門、風扇、敵人…）
```

- **拖錯位置不會壞**，輸出面板會跳出中文提示告訴你該放哪
- 不想要了 → 選取節點按 **Delete**；想暫時關掉 → Inspector 取消勾選 `enabled`
- **暫停選單**每一關都有，不用拖：遊戲中按 **Esc** 或 **P**
- 範本已經放好的設定節點（按鍵、血量、重生、遊戲流程）怎麼調 → [零件手冊 §4](零件手冊.md#4-常用的設定節點)

### 5.1 怎麼拖一個房間

關卡比一個畫面大時，把它切成一格一格的房間：玩家走進哪個房間，鏡頭就跳到那個房間；在哪個房間死掉，就在那個房間重生。

1. **先開格線吸附**（每台電腦設一次）：中間畫面上方工具列打開 **格線吸附**（Use Grid Snap，磁鐵旁的格子圖示），
   再到 **吸附選項 → 設定吸附**（Configure Snap）把 **格線步長**（Grid Step）設成 **16 × 16**
2. 從 `_Template.tscn` 另存的關卡已經有一個對齊畫面的 **Room1**（淺藍色的框）
3. 要第二個房間 → 選取 Room 按 **Ctrl+D** 複製，拖到第一個框的**旁邊**，邊跟邊貼齊，不要重疊也不要留縫
4. 金幣、箱子、敵人這些死掉要放回去的東西，拖到它所在的 Room **底下**

> 有放重生點（Checkpoint）的關卡，**一定要拖 Room**，不然重生點之前撿過的道具死掉後會再出現。

房間大小、重生位置、重生分組 → [零件手冊 §5](零件手冊.md#5-房間-room)

## 6. 沒反應怎麼辦

1. **先看下方「輸出」面板**：⚠ 開頭的中文訊息會告訴你哪裡有問題
2. **再看場景樹上的黃色驚嘆號**：滑鼠移上去會寫哪裡設錯
3. 常見狀況：

| 狀況 | 原因 |
|---|---|
| 改完沒變化 | 忘了存檔（**Ctrl+S**）再按 F6 |
| 拖進去沒效果 | 放錯位置，對照第 5 節；Juice 沒效果也可能是按過 **0** 把 Juice 關掉了 |
| 按鍵沒反應 | 同一顆鍵被兩個東西綁了，輸出面板會寫是哪兩個 |
| 攻擊看起來沒打中 | 擊退力道（`knockback`）設成 0，敵人被打中也不會動 |
| 死掉之後不會重生 | 關卡裡沒有 `RespawnHandler`，從 `blocks/` 拖一個進來 |
| 鏡頭不會跟著換房間 | 關卡裡沒有 `Room`，或兩個 Room 之間留了縫，對照第 5.1 節 |
| 沒有聲音 | 按 **Esc** 打開暫停選單，看主音量／音效／音樂是不是被拉到 0 |
| 「設為主場景」按了沒反應 | 這份關卡是用檔案總管複製來的。在 Godot 打開它 → **場景 → 另存場景為** 存一份新名字，對新的那份設主場景 |
| 更新後輸出面板一堆 `invalid UID … using text path instead` | 不影響遊玩，打開自己的關卡存一次就會消失 |

各種零件專屬的問題，看零件手冊每一節最後的「常見問題」：
[房間 §5](零件手冊.md#5-房間-room)、[Juice §6](零件手冊.md#6-手感組件-juicejuice)、[套皮與 UI §7.5](零件手冊.md#75-常見問題)

還是不行再舉手 🙋

## 7. 重灌／更新專案

專案壞掉，或講師發了新版時。**有用 GitHub 的人看 7.2。**

### 7.1 沒用 GitHub

1. 把 `_my/` 整個資料夾**複製**到桌面
2. **刪掉**整個專案資料夾
3. 解壓新的專案壓縮檔
4. 把桌面的 `_my/` **貼回**專案裡，問要不要取代時選 **全部取代**
5. 用 Godot 重新匯入（同第 1 節步驟 4）
6. 重新設定主場景（第 4 節第 3 步）。沒設之前，`palette` 選「跟標題一樣」的 HUD、選單會有黃色驚嘆號、先用預設配色
7. 有改過 Input Map 的話，重新加一次（[零件手冊 §4](零件手冊.md#4-常用的設定節點)「進階：Input Map」）

大約 30 秒。

### 7.2 有用 GitHub

⚠ **不能刪整個資料夾**：裡面有個隱藏的 `.git` 資料夾，刪掉就跟你的 GitHub repo 斷線了。

1. GitHub Desktop 先 **Commit + Push**（這就是備份）
2. 打開專案資料夾，刪掉**除了 `.git` 和 `_my` 以外**的所有東西
3. 新版壓縮檔解壓到這個資料夾，遇到重複選 **取代**
4. 用 Godot 開啟，等匯入跑完，重新設定主場景（第 4 節第 3 步）
5. GitHub Desktop 會列出這次更新改了什麼 → **Commit + Push**

**第一次建 repo 時**
- GitHub 網頁問要不要加 `.gitignore` → 選 **None**（專案已經有了）
- 在學校電腦：每次上課用 GitHub Desktop **Clone** 下來，下課前 **Commit + Push**，然後**登出** GitHub Desktop

## 8. 匯出網頁版（給別人玩）

### 8.1 安裝匯出範本（每台電腦只要做一次）

1. 上方選單 **編輯器 → 管理匯出範本**（Editor → Manage Export Templates）
2. 按 **下載並安裝**（Download and Install，檔案約 1 GB，要等一下）
   - 講師有給 `.tpz` 檔的話 → 改按 **從檔案安裝**（Install from File）→ 選那個檔案，比較快
3. 看到 `4.7.2.stable` 顯示「已安裝」就完成

### 8.2 匯出

1. 確認主場景是你的關卡（第 4 節）
2. **專案 → 匯出**（Project → Export）
3. 左邊選 **Web**（已經設定好，不用改任何東西）
4. 按 **匯出專案**（Export Project）→ 確認「**匯出時包含除錯**」（Export With Debug）**沒有勾** → **存檔**
5. 檔案會出現在專案資料夾的 `build/web/`

> ⚠ 直接雙擊 `index.html` **打不開**，這是正常的。要上傳到網站才能玩。

### 8.3 上傳到 itch.io

1. 把 `build/web/` **裡面的所有檔案**壓成一個 zip（`index.html` 要在 zip 最外層）
2. itch.io → **Upload new project** → Kind of project 選 **HTML**
3. 上傳 zip → 勾選 **This file will be played in the browser** → 把 `_my/CREDITS.txt` 的內容貼到頁面說明（Description）→ 存檔
4. 分享網址給別人
