# 五週遊戲原型工作坊

你只需要做三件事：**拖節點、選下拉選單、拉數值拉桿**。不用寫程式。

> 選單名稱後面的英文是 Godot 英文介面的原名，找不到中文選項時照英文找。

---

## 1. 安裝（第一次）

1. 下載 **Godot 4.7.2**（Windows 64-bit，**不要**選 .NET 版，也**不要**用更新的版本）
   👉 https://godotengine.org/download/archive/4.7.2-stable/
2. 解壓 Godot，直接執行 `Godot_v4.7.2-stable_win64.exe`（不用安裝）
3. 解壓這個專案壓縮檔到任意資料夾
4. Godot 專案管理員 → **匯入**（Import）→ 選專案資料夾裡的 `project.godot` → **匯入並編輯**（Import & Edit）
5. 第一次開啟會跑一陣子匯入進度條，等它跑完再動

---

## 2. 資料夾規則

| 資料夾 | 能不能改 |
|---|---|
| `_my/` | ✅ **你的東西全部放這裡** |
| 其他所有資料夾 | ❌ 只能看、只能拖，**不要改、不要存檔進去** |

存檔時看一下路徑是不是 `res://_my/...`。存到別的地方，重灌時就會不見。

---

## 3. W1 上課流程

1. **抽卡**：打開 `levels/CardDraw.tscn` → 按 **F6** → 按「抽卡」
2. **逛展示間**：打開 `levels/Showroom.tscn` → 按 **F6**，看看各種零件怎麼動
3. **另存玩具箱**：打開 `levels/_starts/W1_ToyBox.tscn` → **場景 → 另存場景為**（Scene → Save Scene As）→ 存到 `_my/`
   （之後都改 `_my/` 裡的這份，不要改原本那份）
4. **拖東西進去**（見第 5 節）
5. **調數值**：點節點 → 右邊 Inspector 拉拉桿、選下拉選單。滑鼠停在欄位上會有中文說明
6. **試玩**：按 **F6**（執行目前場景）

---

## 4. 建立自己的關卡

要做一個真正給別人玩的關卡時：

1. 左下角「檔案系統」點 `levels/_Template.tscn` → **Ctrl+C**
2. 點 `_my` 資料夾 → **Ctrl+V**（`_my/` 裡會多一個 `_Template.tscn`，這份就是你的關卡）
3. 在 `_my/` 裡那份上按右鍵 → **設為主場景**（Set as Main Scene）
4. 之後按 **F5** 就會直接跑你的關卡，匯出網頁版也是匯出這一關

> 重灌專案後主場景會跑掉，要重做第 3 步。

---

## 5. 東西要拖到哪裡

從左下角「檔案系統」把 `.tscn` 拖到左上角「場景」樹上：

```
你的關卡
├── Player
│   ├── Mechanics   ← mechanics/ 的機制卡（抽到的那張）
│   ├── Juice       ← juice/ 的手感組件
│   └── Abilities   ← abilities/ 的攻擊能力（近戰、遠程）
├── MyControls      ← blocks/KeyTrigger.tscn（自訂按鍵）
└── （直接放在關卡底下） ← blocks/ 的零件（按鈕、門、風扇、敵人…）
```

- **拖錯位置不會壞**，輸出面板會跳出中文提示告訴你該放哪
- 不想要了 → 選取節點按 **Delete**
- 想暫時關掉 → Inspector 取消勾選 `enabled`

---

## 6. 沒反應怎麼辦

1. **先看下方「輸出」面板**：⚠ 開頭的中文訊息會告訴你哪裡有問題
2. 常見狀況：

| 狀況 | 原因 |
|---|---|
| 拖進去沒效果 | 放錯位置，對照第 5 節 |
| 按鍵沒反應 | 同一顆鍵被兩個東西綁了，輸出面板會寫是哪兩個 |
| 攻擊看起來沒打中 | 擊退力道（`knockback`）設成 0，敵人被打中也不會動 |
| 改完沒變化 | 忘了存檔（**Ctrl+S**）再按 F6 |

還是不行再舉手 🙋

---

## 7. 重灌／更新專案

專案壞掉，或講師發了新版時：

1. 把 `_my/` 整個資料夾**複製**到桌面
2. **刪掉**整個專案資料夾
3. 解壓新的專案壓縮檔
4. 把桌面的 `_my/` **貼回**專案裡，問要不要取代時選 **全部取代**
5. 用 Godot 重新匯入（同第 1 節步驟 4）
6. 重新設定主場景（第 4 節第 3 步）

大約 30 秒。

---

## 8. 匯出網頁版（給別人玩）

### 8.1 安裝匯出範本（每台電腦只要做一次）

1. 上方選單 **編輯器 → 管理匯出範本**（Editor → Manage Export Templates）
2. 按 **下載並安裝**（Download and Install，檔案約 1 GB，要等一下）
   - 講師有給 `.tpz` 檔的話 → 改按 **從檔案安裝**（Install from File）→ 選那個檔案，比較快
3. 看到 `4.7.2.stable` 顯示「已安裝」就完成

### 8.2 匯出

1. 確認主場景是你的關卡（第 4 節）
2. **專案 → 匯出**（Project → Export）
3. 左邊選 **Web**（已經設定好，不用改任何東西）
4. 按 **匯出專案**（Export Project）→ 確認「**匯出時包含除錯**」（Export With Debug）**沒有勾** → **存檔**
5. 檔案會出現在專案資料夾的 `build/web/`

> ⚠ 直接雙擊 `index.html` **打不開**，這是正常的。要上傳到網站才能玩。

### 8.3 上傳到 itch.io

1. 把 `build/web/` **裡面的所有檔案**壓成一個 zip（`index.html` 要在 zip 最外層）
2. itch.io → **Upload new project** → Kind of project 選 **HTML**
3. 上傳 zip → 勾選 **This file will be played in the browser** → 存檔
4. 分享網址給別人
