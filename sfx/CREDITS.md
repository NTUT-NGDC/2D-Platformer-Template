# 音效出處與授權

這個資料夾的內建音效全部是**用程式自己合成**的（sfxr 風格：方波、鋸齒波、雜音加上音高滑動與衰減），
沒有使用任何外部素材，以 **CC0（公眾領域）** 釋出，可以自由使用、修改、商用，不需要標註。

產生方式：在專案根目錄執行 `python tools/generate_sfx.py`（只用 Python 標準函式庫）。

| 檔案 | 用途 | 說明 |
|---|---|---|
| `jump.wav` | 跳躍 | 方波往上滑 |
| `land.wav` | 落地 | 低沉的噗 |
| `hurt.wav` | 受傷 | 方波往下滑，混一點雜音 |
| `explosion.wav` | 爆炸 | 越來越悶的雜音 |
| `pickup.wav` | 撿東西 | 兩個音往上跳 |
| `coin.wav` | 金幣 | 兩個高音（B5 → E6） |
| `laser.wav` | 雷射 | 鋸齒波快速往下滑 |
| `beep.wav` | 嗶 | 短短的方波 |

學員自己加的音檔請放在 `_my/` 底下，並在自己的作品說明裡寫清楚出處與授權。
